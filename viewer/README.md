# Cyberpunk RED Stream Viewer

A display-only Godot 4.7 client for the local GM service. It subscribes to
`ws://127.0.0.1:8000/viewer`, draws the encounter roster, and shows the
resolver's own card text when an action resolves. It rolls nothing, computes
nothing, and cannot change the encounter.

## Running

Open `viewer/` in Godot 4.7 and press play, or run it headless-free from a
shell:

```powershell
godot --path viewer
```

Point it at another host or port with either form:

```powershell
godot --path viewer -- --gm-url=ws://127.0.0.1:8000/viewer
$env:CPR_VIEWER_WS = "ws://127.0.0.1:8000/viewer"
```

The window starts transparent so OBS can composite it over the rest of the
scene. Pass `--opaque` for a solid dark background if your capture setup would
rather key it.

The viewer reconnects on its own every two seconds, so the service and the
viewer can start in either order and the service can restart mid-session
without touching OBS. While the link is down a small `GM SERVICE OFFLINE` chip
appears in the top-right; it disappears once the socket is back.

## OBS setup

1. Start the GM service, then the viewer.
2. Add a **Game Capture** (Windows) or **Window Capture** source for
   `Cyberpunk RED Viewer`.
3. Tick **Allow Transparency** so the roster and cards composite over your
   camera and table art.
4. The layout is authored for 1920x1080 and stretches with `canvas_items`, so
   scaling the source keeps the text crisp.

## Layout

| Region       | Content                                                        |
| ------------ | -------------------------------------------------------------- |
| Top left     | Roster: HP, body/head SP, cover, ammo, jams, critical injuries  |
| Bottom right | Resolution card: the resolver's line-by-line arithmetic         |
| Bottom left  | Rules card: a cited answer the GM chose to broadcast            |
| Top right    | Connection warning, shown only while the service is unreachable |

Cards fade out on their own (9 seconds for a resolution, 16 for a rules
answer). Undo and redo show a short reversal card so viewers can follow a live
correction without replaying the original outcome.

## Files

- `scripts/gm_client.gd` - WebSocket subscriber with reconnect and keep-alive.
- `scripts/viewer_root.gd` - scene layout and snapshot routing.
- `scripts/actor_panel.gd` - one combatant's status block.
- `scripts/resolution_card.gd` - the resolved-action card.
- `scripts/rules_card.gd` - the cited rules card.
- `scripts/palette.gd` - shared colours and panel styling.

`.godot/` is generated by the engine and is not tracked; the `*.import` files
beside each asset are, as Godot expects.
